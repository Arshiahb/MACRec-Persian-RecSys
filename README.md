## English

### Overview

This repository contains a research prototype of an LLM-powered agentic recommender for Persian e-commerce reviews. It infers latent user preferences from review history, ranks five candidate products using the supplied evidence, and provides an explanation. The design is inspired by RecMind; it is not a full reproduction of the paper.

### Architecture

The notebook loads a local DigiKala review workbook, cleans recommendation labels and Persian text fields, forms user histories and candidate sets, queries an OpenAI-compatible chat completion endpoint, validates the ranking, and computes HR@K, MRR, and NDCG@5. The API key and endpoint are read from `OPENAI_API_KEY` and `OPENAI_BASE_URL`.

### Data and reported results

Raw Excel/CSV data is excluded from Git. Obtain `keifiat.xlsx` separately from [farshadnp/DigiKalaDataSet](https://github.com/farshadnp/DigiKalaDataSet) and place it at `data/keifiat.xlsx`, or set `DIGIKALA_DATA_PATH`. The two JSON files under `benchmarks/` are the compact benchmark and reported evaluation artifacts. They contain review text and should be handled under the source dataset?s terms and applicable privacy requirements.

Reported evaluation uses 40 category-balanced users. The values below are supplied project results; they are descriptive and depend on the sampled users, model, prompt, and candidate construction.

### Setup

Install dependencies with `pip install -r requirements.txt`. Set `OPENAI_API_KEY` and `OPENAI_BASE_URL=https://api.gapgpt.app/v1`; optionally set `DIGIKALA_DATA_PATH`. Then run `jupyter notebook notebooks/recmind_agentic_recommendation.ipynb`. API calls may incur provider charges.
